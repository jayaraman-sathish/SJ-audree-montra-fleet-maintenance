# SJ Audree Montra Fleet Maintenance

Fleet Maintenance, Breakdown & Uptime Management System.

## Stack
- Angular 18 + TypeScript
- ASP.NET Core / .NET 8
- Microsoft SQL Server
- Entity Framework Core

## Included in this upload bundle
- Application shell and dashboard
- Vehicle Master / Vehicle 360 shell
- PM Obligations screen and workflow
- Appointment scheduling screen
- Service Event / Job Card / Work Item screens
- Initial backend API contracts and in-memory demo endpoints
- SQL Server schema for the core vertical flow
- GitHub CI workflow
- Render blueprint

## Core flow
Vehicle -> PM Obligation -> Appointment -> Service Event -> Job Card -> Work Item -> QC/Release -> Availability/Uptime

This bundle is intended to be uploaded to the `milestone-1-foundation` branch.
