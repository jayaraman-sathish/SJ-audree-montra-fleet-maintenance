# SJ Audree Montra Fleet Maintenance

Fleet Maintenance, Breakdown & Uptime Management System for Montra.

## Locked stack
- Angular + TypeScript
- ASP.NET Core / .NET 8
- Microsoft SQL Server
- Entity Framework Core
- Private object/file storage for photos and documents

## Milestone 1
Foundation, Dashboard, Vehicle Master and Vehicle 360.

## Structure
- `backend/` ASP.NET Core API
- `frontend/` Angular web app
- `database/` SQL scripts/migrations
- `deployment/` Render configuration
- `docs/` implementation notes
